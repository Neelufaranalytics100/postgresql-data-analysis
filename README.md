# Hospital Data Analysis Using PostgreSQL

## 📌 Project Overview

This project analyzes hospital patient data using PostgreSQL and SQL.

The dataset contains information about patient demographics, medical conditions, procedures, treatment costs, length of stay, readmission status, outcomes, and patient satisfaction.

## 🎯 Objectives

- Analyze patient data by medical condition
- Calculate the number of patients for each condition
- Analyze average and total treatment costs
- Examine length of hospital stay
- Analyze readmission patterns
- Evaluate patient outcomes and satisfaction
- Identify useful healthcare data insights

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- Aggregate Functions
- GROUP BY
- ORDER BY
- WHERE
- ROUND
- COUNT
- AVG
- SUM

## 📊 Dataset

The dataset includes the following fields:

- Patient ID
- Age
- Gender
- Condition
- Procedure
- Cost
- Length of Stay
- Readmission
- Outcome
- Satisfaction

## 🔍 SQL Analysis

The project includes SQL queries for:

- Patient counts by condition
- Average treatment cost
- Total treatment cost
- Patient outcome analysis
- Readmission analysis
- Patient satisfaction analysis
